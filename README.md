# Deck Design｜鋼承鈑施工階段分析

繁體中文鋼承鈑施工階段互動分析工具，可離線開啟，也可部署於 GitHub Pages。首頁為 `index.html`，不需安裝套件或建置。

## 使用流程

1. 選擇 Deck 類型、板厚與鋼材性質。
2. 設定 USA SDI 或 UNIFORM、支承型式、載重及原計算跨距。
3. 檢視正負彎曲應力、撓度及最大可用跨度。跨度敏感度拉霸為 0.10–5.00 m，每格 0.05 m；試算與原計算結果分開顯示。
4. 匯出可編輯 Word（DOCX），或列印／儲存 PDF。

## 自訂 Deck 資料庫

「型式與材料」頁下方可展開資料庫，新增型式與各板厚的單位重、I、Sx+、Sx−。資料儲存在目前瀏覽器的 localStorage。

從離線檔改用 GitHub Pages 網址時，請先在舊頁面匯出 JSON，再於新頁面匯入。不同網址及不同瀏覽器的自訂資料不會自動共用。

## 計算與資料來源

- 型錄斷面及 UNIFORM 公式源自使用者提供的「DECK 2017 0531修正」VB 程式。
- UNIFORM：WT =（混凝土自重 + 澆置活載 L.L + 衝擊載重 I.L）+ Deck 自重；I.L 採輸入值。
- USA SDI 依工具現有列式計算，適用版次及條件見網頁與計算書說明。
- 分析範圍為施工階段板跨彎曲應力及撓度；正式使用需核對工程條件與製造商斷面資料。
- 本次 UI 更新保留載重、彎矩、撓度、跨距檢核與 Word 匯出的計算程式。

## GitHub Pages 部署

將本目錄檔案放入儲存庫根目錄，在 Settings → Pages 選擇 Deploy from a branch，來源為 main 分支的 / (root)。`.nojekyll` 使網頁直接以靜態檔案發布。
