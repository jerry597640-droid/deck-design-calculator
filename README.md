# Deck Design｜鋼承鈑施工階段分析

[開啟網頁](https://jerry597640-droid.github.io/deck-design-calculator/) · [Word 操作說明](DECK_操作說明與資料來源.docx)

繁體中文工程試算工具，首頁為 `index.html`，可離線開啟，不需安裝或建置。施工階段依輸入的有效斷面與容許值檢核彎曲應力、撓度。

## 操作流程

1. 選板型、板厚，核對重量、有效 I、Sx± 及鋼材性質。
2. 選 USA SDI 或 UNIFORM、支承跨數，輸入每跨 L、混凝土及施工載重。
3. 查看應力與撓度利用率、荷重情況及彎曲／撓度限跨。敏感度試算為 0.10–5.00 m、每格 0.05 m，不改寫原計算。
4. 核對列式，匯出可編輯 DOCX，或列印／儲存 PDF。

桌面採固定工具列與側邊導覽；手機採單欄表單與底部頁籤。工具列「操作說明」提供可搜尋的填表方式與資料來源，欄位旁亦有直接入口。Word 手冊共 10 頁，含 29 項欄位／操作說明及完整案例。

## 計算與本次修正（2026-10-02）

- 切換 UNIFORM 時，L.L 預設 0.15 t/m²；USA SDI 預設 0.10 t/m²，可再修改。
- USA SDI 比較澆置＋集中施工荷重、澆置＋均佈活載、裸 Deck＋施工活載。修正單跨均佈活載漏入及補上裸 Deck 工況。SDI 撓度使用 W1。
- UNIFORM 使用 WT = 混凝土自重 + Deck 自重 + L.L + I.L，彎矩及撓度均納入 I.L。
- 限跨搜尋從 0 起至 25 m，向下取至 0.01 m；不再漏掉小於 0.50 m 的限跨。
- 空白、零剛度及不合理幾何會停止結果更新與計算書匯出；低於施工載重下限或放寬容許條件時顯示「需補核」。
- 已完成 33 項數值反應與邊界檢查；獨立 Euler–Bernoulli 梁剛度法核對等跨、等 EI 的 1～3 跨均佈梁。簡化撓度係數與精確解差異約 0.16%～0.30%。

本工具未包含 AISI 有效斷面設計、剪力、支承局部承壓、連接、臨時支撐、混凝土積聚及硬化後組合樓板設計。「本項符合」只表示本工具彎曲及撓度檢核，並非整體工程設計認證。

## 資料來源

- [ASC Steel Deck 官方型錄 §1.7](https://ascsd.com/wp-content/uploads/DL021_FloorDeck-Catalog.pdf)：引用 SD-2022 Eq. 2.1-1～2.1-3，核對三組 ASD 荷重及施工最低載重。
- [SDI 官方標準清單](https://sdi.org/codes-standards/sdi-standards/)：SD-2022 與 Supplement 1 版次資訊。
- [SDI NC-2010 Appendix 1](https://sdi.org/wp-content/uploads/2023/07/SDI-ANSI-NC-2010-X.pdf)：歷史簡化梁係數參考，不宣稱為現行標準完整原文。
- 使用者提供的「DECK 2017 0531修正」Form1.vb：內建 19 系列、110 組斷面、混凝土厚度修正與 UNIFORM 公式。內建材料資料須另核對現行原廠型錄。

## 案例與自訂資料庫

「儲存案例」保存當前材料、載重與跨距；「開啟案例」載入成自訂斷面供核對。

「型式與材料」頁可新增自訂型式與各板厚的重量、I、Sx±。資料存於目前網址和瀏覽器的 localStorage；請用資料庫的「匯出 JSON」備份。資料庫 JSON 與案例 JSON 為不同格式。換網址、瀏覽器或裝置不會自動共用資料。
